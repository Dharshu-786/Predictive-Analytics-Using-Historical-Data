# Predictive Analytics Using Historical Data

This project builds a Linear Regression model to predict product sales using historical advertising budget data (TV, Radio, and Newspaper). The project includes data preprocessing, model training, prediction, model evaluation using R² Score, and visualization of actual vs predicted sales.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Model
- Linear Regression

## Result
- R² Score: 0.8994
- Successfully predicted sales with good accuracy.
